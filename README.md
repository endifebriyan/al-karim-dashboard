Dashboard ini harus terlihat seperti perpaduan antara Notion, Linear, Vercel Dashboard, dan Google Analytics, namun menggunakan identitas visual Sekolah Alam Al-Karim dengan nuansa hijau, Islami, natural, dan profesional. Data awal dapat mengambil inspirasi dari profil sekolah, jenjang pendidikan (Toddler hingga SMA), program unggulan seperti Tahfidz, Talent Mapping, Experiential Learning, IT & English, Entrepreneurship, serta modul berita, kegiatan, dan PPDB yang ada di situs sekolah.
